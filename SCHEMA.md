# Public automotive security wiki schema

This repository publishes the automotive cybersecurity subset of a larger private research wiki.

- Dated briefings live under `briefings/automotive/YYYY/MM/`.
- `sources/` contains metadata-only citation records; full captures are not republished.
- Every substantive claim should retain a canonical source URL and evidence boundary.
- Research, threat intelligence, vendor advisories, academic work, and automotive analysis remain distinct source families.
- Historical briefing snapshots are not silently rewritten.
- Confidence labels describe evidence strength, not exploit severity.
